# World clock

Date: 30 September 2026. Scope: the header shows a plain world clock. One dropdown adds a country or removes one that is showing. This is not a release-wide pass of the 20 checks.

The list stays in local storage on this device under `keel.clocks`. It is not sent to the server and does not change either class roster. An empty list stays empty. A missing or unreadable value returns Local, London, New York, Lagos, and Tokyo. Eight clocks is the maximum.

The clocks are the city and the time only. Add or remove is a dropdown beside the language control. Remove lists the clocks that are showing. Add lists the countries that are not showing yet. Eight remains the maximum. A typed name is still resolved by the same matching rules in the library.
