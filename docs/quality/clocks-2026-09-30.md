# World clock

Date: 30 September 2026. Scope: each header clock can be removed, and a country can be added by typing or from a list. This is not a release-wide pass of the 20 checks.

The list stays in local storage on this device under `keel.clocks`. It is not sent to the server and does not change either class roster. An empty list stays empty. A missing or unreadable value returns Local, London, New York, Lagos, and Tokyo. Eight clocks is the maximum.

Typing Ghana or Accra resolves to Ghana. Typing Guinea, or United States, matches more than one place and asks for the list. A choice in the list wins over the typed text. Removing a clock does not ask for confirmation.
