# Public class records

Date: 29 September 2026. Scope: durable records for the public class, and a citation file. This is not a release-wide pass of the 20 checks.

## What changed

When `DATABASE_URL` or `POSTGRES_URL` is set, accounts, progress, review flags, and teacher class files are stored in PostgreSQL. Assessment text is still discarded after review. When neither variable is set, Keel keeps using SQLite in `.data/keel.db`. The public production project `keel` has `DATABASE_URL` on Production only. Preview deployments do not receive it, so a preview does not share the class roster. This machine is not pointed at the hosted database.

`CITATION.cff` names the software, the repository, and the Apache-2.0 licence. No DOI was created.
