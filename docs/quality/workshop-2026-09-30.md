# Workshop

Date: 30 September 2026. Scope: a class project page on the existing record. This is not a release-wide pass of the 20 checks.

The public class remains https://keelai-os.vercel.app. A Vercel preview link is not this class. The local class at http://127.0.0.1:3960 keeps its own SQLite roster. Nothing in this change points this machine at the hosted database.

## What changed

A signed-in person can open Workshop, start a page, and write it with classmates added by display name. Every save is kept. If two people save the same revision, the second save stops and shows the other copy. The open page is checked about every eight seconds, and a draft that is still being typed is not replaced by that check. Publishing lets anyone who is signed in read the page. A draft stays with the owner, the people on the page, and staff. The owner or staff can add a classmate, publish, or delete. People who can write can restore an earlier save and leave a note. A reader of a published page cannot.

The page is markdown rendered as text. Raw HTML is not executed, and a `javascript:` link is not turned into a link. There is no live cursor. The public class runs as short requests, so a socket session was not added.

Deleting an account removes the pages that account owns. The words stay until then. An assessment upload is still read and discarded. The privacy statement on `/data` says so. Workshop pages are `noindex`. The description is the programme sentence, not the page body.
