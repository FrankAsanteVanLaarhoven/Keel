# Phone header, tutor, and clock list

Date: 1 October 2026. Scope: the header stays one row, the tutor does not cover the branch controls while the cookie notice is open, the country list is filled after the page has loaded, and keyboard focus stays on the control that has it. This is not a release-wide pass of the 20 checks. https://keelai-os.vercel.app was not opened for this note.

The header is one scrolling row. Below the wide layout the clocks stay behind World. The mark scrolls with the row, so a focused link is not covered by it. When a focused control is cut off, the row scrolls until the whole control is inside the bar.

The tutor stays in the page until Essential only or Allow the live tutor is chosen. After that choice it sits on the bottom edge, and the footer keeps room for it. The branch controls are not under it.

The clock time still opts out of the hydration check. The add-a-country list is empty in the first render, because region names differ between the server and the browser, and it is filled after the page has loaded. The clocks already on the row keep their catalog names.
