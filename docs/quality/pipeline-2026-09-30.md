# Data pipeline

Date: 30 September 2026. Scope: the Foundry pipeline on this class record. This is not a release-wide pass of the 20 checks.

A branch holds versioned datasets. A dataset is the files that were landed, or the file a transform wrote. A transform is one read. A build runs the transforms in order. Lineage marks a transform out of date when an input hash or the transform itself has changed. The output is another dataset, or an object with a grain. A second delivery of an unchanged branch does not write a new version.

The rows are written by the class records. The same graph is compiled to a Spark batch job and a Flink streaming job and stored with the build. Those jobs do not run. They run when a worker for that engine is connected. The page says so.

The pipeline belongs to the signed-in account. Another student does not see it. Deleting the account removes it. The export file includes it. The page is not indexed.
